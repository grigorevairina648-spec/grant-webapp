# Фотографии

Положите настоящие фотографии в эту папку под этими именами — они сами заменят иллюстрации-заглушки:

- hero-1.jpg, hero-2.jpg, hero-3.jpg — первый экран (люди в путешествиях, на прогулках, экскурсиях)
- tourism-nature.jpg, tourism-walk.jpg, tourism-excursion.jpg — блок «Путешествия должны быть возможны»
- team.jpg — фото команды; person-director.jpg — фото директора

Требования: реальные фото, где люди путешествуют, гуляют, общаются и отдыхают; без «беспомощных» ракурсов.
Размер до ~1600 px по длинной стороне, JPG/WebP, до 300 КБ. Фото проектов и новостей загружаются через /admin/.
